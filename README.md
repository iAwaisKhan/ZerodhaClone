# 📈 Zerodha Frontend Clone

A simple and responsive **Zerodha frontend landing page clone** built using **HTML** and **CSS**. This project helps beginners understand layout structuring, styling, and recreating real-world UI designs. ✨

---

## 🚀 Features

* 🎨 Clean and modern UI
* 📱 Responsive layout 
* 🧩 Organized HTML structure
* 💅 Pure CSS styling without frameworks
* ⚡ Fast and lightweight

---

## 🛠️ Tech Stack Used

* **HTML5** 🧱
* **CSS3** 🎨

---

## ⚙️ How to Run the Project

1. Clone or download the project.
2. Open the `index.html` file in any web browser. 🌐
3. You're good to go! 🎉
